# Культист — мод для Pocket Rogues

Новый класс героя **Культист**: свои 9 навыков, свои цепы и плети, свои перки, своё здание в крепости
(«Обитель Культистов»). Работает на загрузчике модов BepInEx — он уже лежит в архиве, отдельно ставить не нужно.

## Как скачать

1. Справа на странице репозитория нажми **Releases** (или открой вкладку *Releases*).
2. У самой верхней (последней) версии скачай файл **`Cultist_PocketRogues_vX.Y.Z.zip`**.

## Как установить

1. Закрой игру.
2. Открой папку игры: Steam → Библиотека → Pocket Rogues → правой кнопкой → Управление → Просмотреть локальные файлы.
3. Распакуй **всё** содержимое архива прямо в эту папку (туда, где лежит `Pocket Rogues.exe`).
   Если спросит про замену файлов — соглашайся. `winhttp.dll` должен оказаться рядом с `Pocket Rogues.exe`.
4. Запусти игру.

В игре: в крепости построй здание «Обитель Культистов» (рядом с Берсерком), потом в выборе героя выбери
карточку «КУЛЬТИСТ» внизу списка.

## Как обновить

Когда выходит новая версия — скачай её zip из Releases и распакуй в папку игры **так же**, соглашаясь на замену
файлов. Прогресс и сохранения не трогаются.

Чтобы узнавать о новых версиях сразу: вверху страницы репозитория **Watch → Custom → Releases**.

## Что в репозитории

- `install/` — то же, что в zip из Releases (загрузчик BepInEx + мод), можно скопировать в папку игры напрямую.
- `source/mod/` — код мода (C#, BepInEx 5 + Harmony; собирается `dotnet build -c Release`, путь к игре — в `FlagellantMod.csproj`).
- `source/ArtGen/` — генератор пиксельных картинок мода (иконки, оружие, эффекты), `source/art/` — сами картинки.
- `CHANGELOG.md` — что менялось в каждой версии.
