# Оккультное святилище — мод-локация для Pocket Rogues

Отдельный мод (не часть класса Культиста): на этажах **Крипты Пустоты** появляются врата в подлокацию —
святилище культа. Внутри — большой зал с пентаграммой, коридоры с петлями и колоннами и до 16 видов
боковых комнат (оружейные, склады, темница с клетками, скрипторий, оссуарий, галерея, зал совета и другие),
секретные комнаты за ломаемыми стенами с сундуками.

Обитатели живут своей жизнью: культисты читают, молятся, изучают предметы, сидят на скамьях; копейщики и
арбалетчики патрулируют группами, тренируются и стреляют по мишеням, арбалетчики охраняют оружейные;
Старейшина ходит по святилищу с двумя культистами; палач и тюремщик заняты пленниками. Освобождённые
пленники сражаются с культистами.

## Установка

Нужен загрузчик BepInEx — он есть в архиве Культиста из Releases (или в `install/` корня репозитория).

1. Закрой игру.
2. Скопируй папку `install/BepInEx` отсюда в папку игры (туда, где лежит `Pocket Rogues.exe`), соглашаясь на объединение папок.
3. Запусти игру. Настройки появятся в `BepInEx/config/custom.pocketrogues.occultsanctum.cfg`
   (вкл./выкл., шанс врат на этаже, с какого по какой этаж, шанс секретной комнаты).

## Что здесь

- `install/` — готовый мод (`BepInEx/plugins/OccultSanctum`: dll и картинки `SanctumArt`).
- `source/mod/` — код (C#, BepInEx 5 + Harmony; `dotnet build -c Release`, путь к игре — в `OccultSanctum.csproj`).
- `source/artgen/` — скрипты Python/Pillow, которые рисуют картинки мода.
- `source/dev_tools/` — служебные плагины для проверки генерации.
